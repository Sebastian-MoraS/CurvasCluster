# Curvas Cluster

El repositorio se puede dividir en 2 grupos, los que sirven de ayuda para filtros - graficos (los archivos ElbowMethod.py, GraphicsHelper.py, helpers.py), en donde todo se junta en el archivo CurvasEstudio, donde se grafican las curvas filtradas.

El código CurvasEstudio, toma una serie de datos de lo podrian ser medidores inteligentes (MI), estos se filtran según ciertos criterios, obtener las mejores curvas es necesario para tener la mejor tipo de representación posible, esto es necesario para poder escalar correctamente la cargas de un sistema en simulaciones de flujos de potencia.
